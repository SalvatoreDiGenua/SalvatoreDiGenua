## 🚀 Projects

### Angular Boilerplate

A reusable Angular starter and a living reference for modern Angular development.

The project is designed to stay aligned with the latest Angular release and to demonstrate current application patterns through a working example rather than a collection of disconnected snippets.

It currently showcases:

- ⚡ signal-based application architecture
- 🧘 zoneless change detection
- 💧 SSR, hydration and incremental hydration
- ⏳ `@defer` and deferred views
- 🔄 `resource()` and `httpResource()`
- 📝 Signal Forms
- 💉 modern dependency injection with `@Service()` and `inject()`
- 🌍 Transloco with Italian and English translations
- 🔎 SSR-safe SEO infrastructure
- 🎨 Tailwind CSS 4 and Prettier class sorting
- ♿ accessibility-oriented defaults
- 🧪 Vitest, ESLint and formatting tooling

The home page is a single scrolling showcase that explains these features while also using them in the application itself.

### ngx-request-lock

An Angular library for coordinating request state across UI elements and HTTP requests. It uses a shared `requestId` to connect pending state with the request lifecycle, making it easier to prevent duplicated or overlapping interactions.
